# すいみんチェック

睡眠時間と登校を毎日記録して、睡眠と登校の関係・今夜の目標・明日からの課題を見られるスマホ向けアプリです。

- アプリ本体は `index.html` 1ファイルだけです。GitHub Pages で公開すると、アカウント登録なしでリンクから使えます。
- 記録は使う人のブラウザの中（localStorage）だけに保存され、どこにも送信されません。
- 内容は書籍の「睡眠表」ワーク（p.38〜41）と、三池輝久『子どもの夜ふかし 脳への脅威』（集英社新書）のヒントをもとにしています。

# 若夏保育園 登降園アプリ（`hoikuen/index.html`）

園児の登園・退園をワンタップで記録し、延長保育の時間と料金を自動で計算するアプリです。玄関のタブレットやスマホで使う想定です。

- **登降園**：園児ごとの「登園」「退園」「欠席」ボタン。時刻の修正、お迎えの人、メモも記録できます。延長保育中の子はオレンジで表示します。
- **記録・延長**：月ごとに登園日数・延長回数・延長時間・延長料金を集計。CSV（Excel用）で保存できます。
- **園児**：名前・クラス・認定区分（標準時間／短時間／個別時間）を登録。
- **設定**：保育時間、延長の単位と料金、猶予時間、バックアップと復元。
- 記録はその端末のブラウザの中（localStorage）だけに保存され、外部へは送信されません。

# 若夏保育園 延長保育の帳票アプリ（`hoikuen/enchou.html`）

延長保育の記録用紙（利用簿・お迎え表など）を写真に撮ると、内容を読み取って次の帳票を作ります。A4 で印刷でき、「PDFに保存」もできます。

- **月統計**：利用した園児数・延べ回数・延べ時間・合計金額、クラス別、日別の人数、お迎えの時間帯、領収済み／未収。
- **個人請求**：園児ごとの請求書（宛名・請求金額・支払期限・日ごとの明細）。
- **領収証と控え**：A4 1枚の上半分が保護者用の領収証、下半分が園で保管する控え。入金を受けたら「発行」すると通し番号がつきます。
- **月一覧**：園児×日付の一覧表（A4横）。日ごとの単位数・回数・時間・金額・領収番号。

使い方

1. 「設定」で料金（単位と単価、または1回いくら）、園の住所・電話・園長名、Claude の API キーを入れます。
2. 「園児」で名簿を作ります（同じ端末の登降園アプリの名簿を取りこむこともできます）。
3. 「写真」で記録用紙を撮影 →「写真を読み取る」→ 一覧を確認・修正 →「記録に追加」。
4. 「帳票」で月を選び、4種類の帳票を表示・印刷します。

- 写真の読み取りには Anthropic の Claude API（`claude-opus-5-5`）を使います。写真と API キーはその端末から Anthropic へ直接送られます。キーがなくても、写真を見ながら手で入力できます。
- 記録は端末のブラウザの中（localStorage）だけに保存されます。写真そのものは保存しません。
